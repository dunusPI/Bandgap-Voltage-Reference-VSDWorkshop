## 📖 About

This repository documents my learning journey through the VSD Bandgap Voltage Reference workshop. Each day covers the underlying theory along with the lab experiments carried out, with notes, observations, and results captured for future reference.

## 🗂️ Repository Structure

The documentation is organized day-wise:

```
Bandgap-Voltage-Reference-VSDWorkshop/
├── Day1/
│   └── README.md
├── Day2/
│   └── README.md
├── Day3/
│   └── README.md
└── ...
```

Each `DayN` folder contains a `README.md` documenting:

- 📘 **Concepts** covered that day
- 🧪 **Lab experiments** performed
- 📝 **Observations and results**
